# 📚 Research Document Q&A System

A RAG (Retrieval-Augmented Generation) pipeline using LangChain, FAISS, and Google Gemini (free tier).
Ask natural language questions about your PDF research papers and get cited, grounded answers.

## How it works

```
PDF files → Load → Chunk (800 chars, 150 overlap) → Embed (gemini-embedding-001) → FAISS index (disk)
                                                                    ↓
                        Your question → Embed → FAISS similarity search (top 4 chunks)
                                                                    ↓
                                            gemini-2.5-flash → Answer + Sources
```

## Project Structure

```
rag_project/
├── docs/            ← Put your PDF research papers here
├── vectorstore/     ← FAISS index (auto-generated by ingest.py)
├── src/
│   ├── ingest.py    ← Run once: loads PDFs, chunks, embeds, saves FAISS
│   └── qa.py        ← Run to ask questions interactively
├── check.py         ← Run to see which models your API key supports
├── .env             ← Your Gemini API key (never commit this!)
├── requirements.txt
└── README.md
```

## Setup & Run

### 1. Get a free Gemini API key
Go to: https://aistudio.google.com/app/apikey

### 2. Create a virtual environment
```bash
python -m venv venv

# Activate — macOS/Linux:
source venv/bin/activate
# Activate — Windows:
venv\Scripts\activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Add your API key
Edit `.env`:
```
GOOGLE_API_KEY=your_actual_key_here
```

### 5. Check which models your key supports (recommended first step)
Edit `check.py` and replace `YOUR_GEMINI_KEY_HERE` with your key, then:
```bash
python check.py
```
Look for:
- Models with `embedContent` → use for embeddings in ingest.py and qa.py
- Models with `generateContent` → use for LLM in qa.py

### 6. Add your PDFs
Drop any PDF files into the `docs/` folder.

### 7. Build the vector index (run once)
```bash
python src/ingest.py
```
> ⏳ Takes ~2-3 min for ~160 chunks due to free tier rate limits (auto-handled).
> Re-run only when you add new PDFs.

### 8. Ask questions
```bash
python src/qa.py
```

## Stack

| Component | Tool | Notes |
|---|---|---|
| Framework | LangChain (LCEL) | Modern chain syntax |
| LLM | gemini-2.5-flash | Free tier, generateContent |
| Embeddings | gemini-embedding-001 | Free tier, embedContent |
| Vector Store | FAISS | Local, no server needed |
| PDF Loader | PyPDFDirectoryLoader | Handles multiple PDFs |
| Chunking | RecursiveCharacterTextSplitter | 800 chars, 150 overlap |

## Free tier limits
- Embeddings: ~100 req/min → handled with batching + delays in ingest.py
- LLM (gemini-2.5-flash): 500 req/day → plenty for Q&A use

## Tips
- Run `check.py` first on any new API key to see available models
- The system only answers from your uploaded PDFs — no general knowledge
- Re-run `ingest.py` whenever you add new documents
- Delete `vectorstore/` and re-run `ingest.py` if you change the embedding model
- Never commit your `.env` file or paste your API key in public
